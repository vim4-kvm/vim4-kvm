# M6 手动开启 HDR

1. 在 Mac mini M6 打开 **苹果菜单  → 系统设置 → 显示器**，选择连接 VIM4 的外接显示器，以本次 EDID 名称为准。
2. 打开 **高动态范围**，保持本次测试指定的分辨率和刷新率。若没有这个开关，记录该情况，不修改其他设置。

菜单名称依据[Apple：在 Mac 上播放 HDR 视频](https://support.apple.com/zh-cn/102205)。
开关打开后仍由板端有效 HDMI DRM infoframe 确认真正的 PQ 输入，不能只凭界面开关判定。
切回 SDR 时在同一位置关闭“高动态范围”，测试结束恢复初始状态。
