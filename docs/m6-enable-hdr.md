# M6 手动开启 HDR

可由用户在 **Mac mini M6 本机物理操作**；用户已于2026-10-30另授权通过One-KVM MCP完成此项准备。
代理必须先截图、只做必要操作，不单按Shift、不在中文输入法下type；结束恢复HDR初始状态并截图。
MCP失败停止操作；候选下MCP不可用时回5.15恢复，不改用其他HID接口。

1. 点左上角 **苹果菜单  → 系统设置 → 显示器**，选择连接 VIM4 的外接显示器（当前 EDID 名称 **RTK-CONTROL**）。
2. 打开 **高动态范围**，保持当前 **3840×2160、60 Hz** 设置，画面稳定后告知测试人员“已开启 HDR”。若没有这个开关，请告知，不必修改其他设置。

菜单名称依据[Apple：在 Mac 上播放 HDR 视频](https://support.apple.com/zh-cn/102205)。
开关打开后仍由板端有效 HDMI DRM infoframe 确认真正的 PQ 输入，不能只凭界面开关判定。
切回 SDR 时在同一位置关闭“高动态范围”；只有测试人员安排切换项时再操作。
