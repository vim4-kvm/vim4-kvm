# 厂商能力对照与剩余门禁

本页管能力追平的范围与依赖；表中“实现”“部署”“验收”分别判断，不作为当前完成率。
当前内核身份见[主线入口](../kernel-mainline.md)。
导航：[能力表](#能力表)、[保护退出](#保护退出)、[实施顺序](#实施顺序)、[性能](#性能与证据)。

## 能力表

目标是同板适用功能及同条件性能不低于厂商基线；显示、采集、音频和编码须共存，不能独占 VPU。
核心用标准框架；外围可先移植厂商实现，再整理。私有 ABI 是否保留按真实消费者判断。
“缺失”不等于硬件不支持；“无法做到”限定当前授权、SDK、密钥、TA 或固件资料条件，
不能据缺源码否定可合法使用的匹配固件。选装能力先证明布线和硬件，不冒充本板默认启用。

| 任务 | 按需读取 |
|---|---|
| 显示、VPU、图像处理 | [显示](display.md) |
| HDMI 输入、编码和解码 | [媒体](media.md) |
| 全部音频路由与处理 | [音频](audio.md)、[硬件清单](audio-board-checklist.md) |
| 计算、存储、总线、网络及 PM | [平台](platform.md)、[PM 窗口](platform-pm-board-checklist.md) |
| MIPI、相机与其他接口 | [成像](imaging.md) |
| USB、按键、ADC、watchdog 等 | [外设](peripherals.md) |
| 安全、固件与诊断 | [安全](security-debug.md) |

能力行 ID 用于追踪，历史计数不能当作当前完成率；精确文件行号仅对固定快照有效。
缺少外设、资料或合法固件时保留边界，不编排没有可执行内容的验收。

## 保护退出

保护只有在实现与对应实测都成立后退出，应用重启能用不等于驱动完成。

| 保护 | 退出前必须证明 |
|---|---|
| Wave5 失败隔离 | DMA 停止、取消、真实固件硬锁及多实例恢复；健康固件注入不覆盖全部硬锁 |
| RX 短暂无效测量 | 与真实失锁分开，标准 lease/事件与资源归属，稳定段不无故重建 |
| 深色、HLG、隔行及像素重复限制 | 相应处理链与真源逐帧/场验证；NV12 不代表原生深色 |
| 音频未就绪 | generation 资格确认、可取消重开及非静音输出，不能把静音当恢复 |
| 固定显示交接 | DRM/KMS 所有权、EDID/HPD/modeset/音频/PM 与采集共存 |
| GPU 固定电压 | 可信板型分档表与 PWM 标定，不能据单个厂商字段试压 |
| 常开域与挂起拒绝 | 全部 DMA 消费者停稳及上下文恢复，固件必需域不盲关 |
| 启动缺少随机种子 | 新鲜种子、正确交接和无陈旧回退，经可恢复启动与跨启动验证；晚期 hwrng 不能替代 |

HEVC 非对齐可见尺寸已有限定范围交付，旧内核或能力探测失败仍回退，范围见[媒体](media.md)。
HLG 实现与真实源未验的区别以[HDR](../hdr.md)为准。

## 实施顺序

稳定输入和生命周期 → DMA 停止与恢复 → 显示采集共享资源 → 原生显示、输出音频与解码 →
设备 PM → 有现场恢复条件的系统挂起与唤醒。扩展计算和外设按实际依赖插入。
解码可离线推进，但正确首帧、安全退出及现场 RESET 条件不成立时不得跳门禁上板。
当前不排挂起、引导区写入或无真实硬件的扩展验收；不要照历史任务名另起重复实现。

RX 曾把测量空窗误判失锁，同链路对照与修复见[记录](../bringup/2026-10-23-hdmirx-vendor-comparison.md)；
不能直接要求用户换线，也不能从短测推断所有物理问题已解决。
详细恢复与未验项各在能力子表保留一处。

## 性能与证据

功能通过不等于性能通过，按[性能协议](../performance-baseline.md)做同条件配对，
不能把缺失记零、让单轮 FPS 或并行组抵消独立负载失败。
GPU 默认策略已有[限定实测](../bringup/2026-10-31-kbase-r11-policy.md)，不代表统一候选全门禁。
Wi-Fi 的长短轮次与未验传输见[平台](platform.md)，不能跨条件拼接成全面通过。
[快速性能窗口](../bringup/2026-10-31-p0-2-performance.md)受运行时和标记阻断，
[PM 窗口](../bringup/2026-11-02-p0-2-pm-window.md)只完成基线 idle；其余缺测仍不确定。
音频、光学、长期增长及缺工具项独立报告，预算由 `python3 tools/perf-baseline.py matrix` 输出。
