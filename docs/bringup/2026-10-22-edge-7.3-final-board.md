### 浏览器与 Wave5

仍在同一独占窗口依次执行：

```sh
python3 -u build/kernel-edge/final/run-browser.py h264 0,1,5,7,8,10,14,17,18
python3 -u build/kernel-edge/final/run-browser.py h265 0,1,5,11,14,16,17,18
python3 -u build/kernel-edge/final/smoke-4k.py
```

前两个矩阵先正向、再反向各一次。测试真实 WebRTC 解码尺寸、三处帧号/校验和、
理想三原色、JPEG HTTP 200、3 秒解码计数与输入时序；HEVC 矩阵在开始前拒绝
非 8 对齐可见尺寸。没有复测已知会导致内核等待的 1366×768 HEVC。

| 矩阵 | 实际结果 |
|---|---|
| H.264 | 9 模式、18 次通过，实际 video/H264；SSRC 始终 3727020646 |
| H.265 | 8 模式、16 次通过，实际 video/H265；SSRC 始终 1958291755 |
| 720×400@70 输入 | H.264 前/返 60.2/60.6fps；H.265 两次均达到目标门槛，输出按约 60fps 上限验收 |
| 4K60 矩阵 | H.264 前/返 59.8/60.1fps；H.265 两次约 59.9fps |
| 回到 VGA 后资源 | 两个矩阵各自首尾均为 14 objects / 138846208 bytes，CmaFree=368224 KiB |

所有矩阵窗口达到 `min(60, 输入 Hz) × 85%` 的测试门槛；首次 H.264 VGA 窗口
为 54.6fps，不能称每个 60Hz 窗口都达到 60fps。其余低帧率输入按 24/30/50fps
分别验证，70Hz 不宣称输出 70fps。原始样本、资源快照和 JPEG 保留于
browser-h264.jsonl、browser-h265.jsonl 及同目录，不把短矩阵当长期稳定性证明。

4K60 独立短测使用物理 HDMI 运动源，两种编码各 3 秒预热、15 秒采样，Chrome
156.0.8078.47。实际 3840×2160：H.264 为 60.0446fps，H.265 为 59.9678fps，
各自 freezes/dropped/lost 增量均为 0，呈现回调 >50ms 为 0。
日志 smoke-4k.jsonl；此 smoke 不解析帧内标记，内容证明来自前面的矩阵，
不把两者合成为端到端延迟、音频或长时间稳定性验收。音轨能量为 0，未测试声音。

### GPU、IR、Wi-Fi 与温控

在两锁内依次运行 `gpu-check.py`、`wifi-check.py`、`final-proof.py`，均在本任务
`build/kernel-edge/final/`，日志为 gpu.jsonl、wifi.jsonl、final-proof.log。
IR 验证限自动键表/协议/模块注册，不含物理遥控器和按键动作。

GPU 保持 simple_ondemand，复用板上既有 surfaceless EGL/GLES 负载，不改 OPP/PWM。
真实 renderer 为 Mali-G52 r1 (Panfrost)，Mesa 25.2.8；连续 10 秒渲染 304 帧，
挂起后再次渲染 3 秒为 91 帧，均 gl_error=0、像素回读有效。连续负载 99 次采样
为 800MHz；空闲 59/60 次 suspended，观察到 250/400MHz；再次负载 30 次为
800MHz。证明自动升频、空闲挂起和再次渲染，未重做五档手动切换或长期压力。

Wi-Fi 原本软件禁用。临时启用后 STA 扫描成功，保存的 WPA3 连接激活，
`iw dev wlan0 link` 显示 5200MHz、NETGEAR_5G_Game，取得 192.168.50.156/24。
`ping -I wlan0 -c 5 -W 2 192.168.50.1` 实际 5 transmitted / 5 received、0% loss。
结束恢复 `nmcli radio wifi` 为 disabled。没有改连接凭据、P2P、AP、地区、固件或
无线驱动；未做外网/DNS、吞吐、漫游或真实 P2P 对端验收。

首启风扇 14% / 49500m°C，期末 15% / 50200m°C，sensor_fault 始终为 0；
期末六温区为 52200、49700、49600、49600、49400、49600m°C。
百分比是控制输出，不是 RPM；这些是短测前后快照，不是长时峰值证明。
manager、One-KVM、HDMI、gadget、PD 均 active，无 failed units，LUN 为空。
读取 eMMC FIP 的 SHA256 仍为
`751490703dc2f8ccee199ffe083b2ba5937cc598ec0e9e718f36c863a164e9e0`，
