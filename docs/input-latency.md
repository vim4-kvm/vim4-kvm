# 键鼠输入验证

## 复测入口

Mac 同时作为浏览器客户端和 VIM4 的 USB 被控机，SSH 与应用已正常运行。
关闭其他自动输入任务，测试期间不要操作键鼠。测试会短暂覆盖各显示器，
建立独立无扩展 Chrome 会话，把方向键、移动、点击、滚轮发送给临时原生窗口；
不向原有终端或文档主动输入。结束恢复指针与前台应用，不修改系统输入设置。

```sh
swiftc tools/input-target.swift -o /tmp/vim4-input-target
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
  node tools/input-check.mjs /tmp/vim4-input-target logs/input-check
python3 tools/input-summary.py logs/input-check
```

可在最后追加应用 URL，默认 http://192.168.50.210:8080。
原生窗口有 40 秒超时退出；发送脚本在结束时先释放输入，再关闭窗口。
两份日志为 PREFIX-browser.json 和 PREFIX-host.jsonl，仅记录测试窗口的键盘事件
及鼠标位置变化。若需要中止，可等待超时恢复桌面。

时间起点为浏览器 WebSocket.send 调用，终点为被控 Mac 测试应用收到原生事件；
移动的终点用 1ms 请求周期轮询指针（实际调度周期可能更长）。两者同一台 Mac，
汇总拒绝浏览器墙钟/单调时钟映射误差超过 2ms 或事件计数不匹配的样本。
它不包括物理按键扫描、浏览器派发前等待、视频回传及显示器发光。
不是完整的手到画面延迟，也不能推广到其他客户端或网络。

## 2026-10-13 结果

组件 1.0.3+vim4.20261013.5，NanoKVM 94bd27d，绝对鼠标模式，4K WebRTC
连接同时运行；原界面与生产代码未修改。

| 输入 | 样本数 | 中位数 / 最大值 |
|---|---:|---:|
| 键盘按下 | 20 | 4.01 / 19.02ms |
| 键盘释放 | 20 | 3.73 / 6.11ms |
| 绝对鼠标移动 | 20 | 2.83 / 6.52ms |
| 鼠标按下 | 5 | 3.49 / 4.41ms |
| 鼠标释放 | 5 | 3.27 / 3.77ms |
| 默认方向滚轮 | 4 | 3.69 / 4.11ms |

20 次短按均对应一按一放，没有重复或缺失。长按右方向键约 2 秒，发送端模拟
多次浏览器重复 keydown，但线上只有一份按下与一份释放报告；被控 Mac 产生
19 次重复事件，首次等待 500.39ms、后续间隔中位 83.88ms。这与读取到的系统
repeatDelay=0.5s、repeatInterval=1/12s 相符，重复由被控机产生，不由浏览器连发。
松开后观察 600ms 未继续重复。合成窗口 blur 也在约 4.77ms 后收到释放并停止重复。
普通字母在原生文本编辑器中的长按行为还受应用/重音菜单影响，本轮使用方向键，
不把其结果当成所有字母、输入法、组合键的验证。

### Mac 自然滚动

已复现反向：浏览器 deltaY=+100，经默认方向 -1 发送 HID wheel=-1；被控 Mac
报告 `isDirectionInvertedFromDevice=true`，得到原生 scrollingDeltaY=+0.1。
将原界面的 **鼠标 → 滚动方向 → 向下**（值 +1）选中后，同一 deltaY=+100
发送 HID wheel=+1，被控端得到 scrollingDeltaY=-0.1，恢复预期方向。
正负两个方向各测两次一致。无需修改 HID 描述符或为所有客户端反转协议。

这个选择保存在当前浏览器 localStorage。测试只修改独立测试配置，不改变用户
正在使用的 Chrome/Safari 设置；用户需在实际使用的浏览器选择一次。
不能根据控制端是 macOS 就推断被控端的滚动配置。

证据：logs/input-{browser.json,host.jsonl,summary.json}。短测不足以覆盖突发鼠标
高频流量、相对鼠标、真实切应用、网络断开与多客户端同时按键。尤其前端键盘
没有像鼠标一样订阅 WebSocket 重连生命周期，服务端在最后一个连接离开时才
归零 HID；多客户端断开时的按键归属需要单独验证，不能把 blur 通过等同于断网通过。

固化脚本后再次实机执行（logs/input-tools-check-*）：键盘按下/释放中位数
4.27/4.24ms，绝对移动 2.85ms，19 次长按重复、松开和 blur 释放正常，
两种滚轮方向复现一致。脚本成功退出并恢复桌面。
