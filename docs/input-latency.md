# 键鼠输入验证

本页管 USB 修复后的输入回归、长按和滚轮判读；不是手到画面的端到端测量。
导航：[复测入口](#复测入口)、[长按](#手动对照-backspace-长按)、[滚轮](#滚轮语义)、[证据与边界](#证据与边界)。

## 复测入口

仅在授权的被控 Mac 上测试，不能向开发机注入 HID。关闭其他输入任务，测试期间不要操作键鼠。
测试临时覆盖显示器并使用独立无扩展浏览器与原生窗口；不向原终端或文档输入，
结束释放按键、恢复指针和前台应用，不改系统输入设置。

构建与调用顺序见[原生目标](../tools/input-target.swift)、[发送脚本](../tools/input-check.mjs)
及[汇总器](../tools/input-summary.py)的头注释、参数入口。先构建目标，再发送，最后汇总。
中止时等待原生窗口超时恢复；日志只记录测试窗口的键盘和指针事件。

端点是浏览器发送调用到同一 Mac 原生窗口收到事件；移动由轮询指针确认，实际调度可能慢于请求周期。
同钟映射和事件数量必须通过汇总校验。不包含物理扫描、发送前派发、视频回传或屏幕发光；
不能推广到别的客户端和网络，也不能叫纯 USB 总线延迟。

## 手动对照 Backspace 长按

在被控机打开[长按页](../tools/key-repeat.html)，保持浏览器和系统输入设置一致，
分别测直连键盘与 KVM；KVM 轮先进入远程画面，再点击被控页开始。
每条路径重复测量，结束前导出，关闭页面会丢失内存数据。有效时长与样本资格以页面实现为准。

持续频率与首次等待分开；保留中途释放事件以发现被拆成反复按放。
失焦、隐藏、合成事件或未释放的异常轮保留原始数据，不进入比值。
浏览器不能判断是否真的持续按住；频率差不能单独定位根因。
页面事件不是 USB 报告频率或原生应用删除速度，字符减少只是计数可视化。

## 滚轮语义

控制端系统不能推断被控端自然滚动设置；方向偏好按实际使用的浏览器保存。
UU 像素增量与普通 HID 刻度不同，不能用一个历史位移比做通用补偿。
同一输入事件换算出的总刻度应合并发送并保留余数，避免拆成突发报告；
边界以 One-KVM `src/uu_remote/input.rs` 的 MouseScroll 分支为准。
按[接收探针](../tools/uu-scroll-probe.swift)分别测直连 UU、经 KVM 的 UU 和网页，
固定鼠标与节奏，用同一原生点单位比较；事件数不等于物理刻度。
不能 ptrace 实时视频进程，会明显扰动视频。调查及用户主观改善反馈见[滚轮快照](archive/uu-scroll.md)，
尚不证明像素滚动与直连完全一致。

## 证据与边界

历史短测日志为 `logs/input-{browser.json,host.jsonl,summary.json}` 和 `logs/input-tools-check-*`：
方向键长按、松开和合成 blur 释放正常，不能覆盖字母重音菜单、输入法或所有组合键。
未覆盖高频鼠标突发、相对鼠标、真实切应用、断网及多客户端同时按键。
尤其键盘重连与最后连接离开时的 HID 归零不是同一生命周期；
blur 通过不能当作断网释放通过，多客户端按键归属仍需独立验证。
