# 内核

本页管厂商内核维护、USB 重枚举与风扇部署；身份和启动布局以[主线入口](kernel-mainline.md)为准。

## 构建

来源和分支以[工作区清单](../workspace.toml)及[内核锁](../packaging/kernel/sources.toml)为准。
内核树只放 Linux 文件系统，不能检出到大小写不敏感的 Mac 文件系统；不拿第三方整套内核替换官方基线。
构建和打包使用[镜像入口](ubuntu-image.md)与[内核构建器](../packaging/kernel/build.sh)，不复制旧手工命令或产物清单。

厂商模块调试时先确认实际队列所有者。采集模块被 tvpath 引用时须先解除引用再卸载；
不得因另一个进程关闭视频节点而停掉正在采集的所有者。
编码器最后关闭必须真正关电，不能误调用上电函数。采集写出须保留完整分辨率，
不能让压缩或双写降采样破坏 VFM 消费者。

## HID 重新绑定

f_hid 的功能实例状态与每次绑定的字符设备必须分别管理：
等待队列、锁和接收链表只在实例分配时初始化；旧字符设备由打开文件持有到最后关闭。
只修等待队列仍发生过链表损坏。重新绑定不能重置仍注册在 epoll 中的队列。
实现见主内核 `drivers/usb/gadget/function/f_hid.c`；应用切换 USB 功能前关闭 HID 的保护继续保留。

修复为内建，必须装完整内核并重启。确认已运行修复版本、停止应用并独占板子后，
按[重绑定检查器](../tools/hid-rebind-check.py)的头注释和帮助执行；禁止在旧内核试跑，会触发已知 panic。
检查须让 HID 文件跨绑定保持 epoll 注册，再覆盖注销和关闭；恢复应用后验实际键鼠、音视频及内核日志。

## CRG USB 控制端点重连

重连排空期间继续消费旧传输完成事件，但禁止新 SETUP；否则状态请求重复入队会 panic。
恢复状态检查还不够：必须登记 gadget IRQ，使解绑等待在途中断，并在锁内检查异步回调开关。
禁用期间不建 SETUP 或 STALL 请求，不发 disconnect；不能解锁后补发 STALL 跨过重置留下 EP0 请求。
这与 f_hid 的文件生命周期是两种故障。

实现与离线事件测试见 common_drivers 的 `drivers/usb/crg/`、`test_setup_events.py`。
部署后更新 initramfs 并重启，核对运行模块 build ID，再做独占重绑定和应用切换；
磁盘模块已替换不能证明运行修复已生效。

## 自动风扇与编码器频率

风扇策略以主内核 `drivers/misc/khadas-mcu.c` 和
`drivers/thermal/khadas_mcu_fan.c` 为准；厂商策略离线检查入口见[策略测试](../tools/test-fan-policy.sh)。
控制百分比没有测速反馈，不能写成 RPM；读温状态是上次采样，输出状态是最后成功写入值。
管理器保存阈值并在开机恢复，不靠修改设备树。
安静模式由单个内核任务独占，不同时交给 thermal governor；CPU 过热保护继续保留。
读温故障时安静模式的散热余量低于旧全速策略，不能把安静当作故障安全等价。
实现、恢复与回退证据见[安静风扇](bringup/2026-10-20-edge-quiet-fan.md)和[启动恢复](bringup/2026-10-20-edge-recovery.md)。
阈值调节已迁移，不能沿用早期“未迁移”结论。内建驱动部署须使用完整内核及同次模块。

编码器提频配置以[板级配置](../board/90-vim4-encoder.conf)为准，由[安装器](../board/install.sh)安装。
已加载模块须重启生效；模块在 initramfs 内时先更新它。回退删除该配置、更新 initramfs 后重启。
提频短测不能证明所有板子、负载和环境都稳定。

## 安装与回退

主线按[整包升级合同](kernel-mainline.md#正式构建与整包升级)执行；
厂商安装行为以[安装脚本](../tools/kernel-install.sh)为准，操作前核对它生成的启动项和保留版本。
保留模块目录隔离，不能混装不同构建。解包必须保护系统目录符号链接，
见[/lib 事故](bringup/2026-10-12-custom-kernel-lib-symlink.md)。

先证明串口可选保留启动项，再变更默认项；按实际启动配置选择回退，不硬编码菜单序号或旧版本链接。
启动变量和 overlay 的相对关系须一起保留，换 DT 目录不能丢 overlay。
当前配置来源见[启动布局](kernel-mainline.md)及[工作区](workspace.md)。
