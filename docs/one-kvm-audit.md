# One-KVM VIM4 功能复核（2026-10-14）

基线：One-KVM `5b3df497`，板上 `vim4-onekvm 2.5.1+vim4.20261014.6`，
管理器 `7489ba1`。本次核对网页入口、服务实现、包内容和板上权限/依赖，
未登录替换用户会话、启用新服务、重启板子或卸载正在使用的虚拟盘。
“保留实现”不等于“已经在 VIM4 验收”。历史实测细节见 [上板记录](bringup-log.md)。

## 明确尚未完成的适配

| 功能 | 证据与缺项 | 建议顺序 |
|---|---|---|
| 网页终端 ttyd | 扩展固定使用 `/usr/bin/ttyd`，板上不存在；还要创建 `/var/run/one-kvm/ttyd.sock`，khadas 无权创建其父目录，服务未配置 RuntimeDirectory。仅补二进制不够 | 优先补包依赖、运行目录和网页终端验收 |
| Gostc、EasyTier、FRP | 扩展入口存在，但 `/usr/bin/gostc`、`easytier-core`、`frpc` 均未安装；当前包也未包含。EasyTier 的 TUN 网络模式还需权限与设备配置审查 | 补可选依赖及启停生命周期，再以实际服务器配置验证 |
| 硬件看门狗 | 直接以应用用户写打开设备；板上 `/dev/watchdog{,0}` 是 root:root 0600，khadas 不可写。不能只把“发现设备”当作可用 | 先确定板级管理归属及三应用切换行为，再做权限和故障恢复验证 |
| One-KVM 网页在线升级 | VIM4 的 `start_upgrade` 明确拒绝上游通用二进制，尚未接入 VIM4 Ubuntu 包更新流程；当前使用部署工具安装 deb | 接入适配包通道，保留依赖预检与配置 |

## 当前明确不支持或缺外设

| 功能 | 当前边界 |
|---|---|
| ATX 电源/复位、状态检测 | 未连接 ATX 硬件，平台能力报告不支持；不可用普通 GPIO 冒充。WOL 是另一条软件路径，尚未验证目标机器唤醒 |
| 多虚拟盘 / 多 LUN | 适配层只接受 1 个 LUN；请求 8 个会明确失败 |
| USB 麦克风回传 | VIM4 OTG 分支拒绝启用 UAC；HDMI 声音回传不等于 USB 麦克风 |
| One-KVM 管理 USB 网桥、描述符 | 由公共板级服务拥有，One-KVM 不提供重建或改写；虚拟介质挂载期间替换 NCM |
| 蓝牙 / CH9329 HID | VIM4 平台只公布 OTG 和 none；额外后端未做本板适配验收 |

对应实现：[平台能力](../One-KVM/src/platform/linux.rs)、
[OTG 服务](../One-KVM/src/otg/service.rs)。这些边界需要新增适配或外设，不是打开开关即可支持。

## 已有实现，但尚未完成实机验收

| 功能 | 现有证据与仍需验证的部分 |
|---|---|
| RustDesk、VNC、RTSP | 保留原生服务和共享视频管线；板上当前均关闭。未验证客户端协商、音视频、控制和同时连接 |
| WebRTC 音频 | Opus WebSocket 已解码出非零 PCM；早期 WebRTC 音轨统计能量为零，尚无完整可听验证，不能宣称两条通路都通过 |
| HDR 曲线 | 参数保存、重载已经验证；本轮输入为 SDR，One-KVM 的真实 HDR 画面效果尚未验收 |
| Ventoy | 256 MiB 创建、USB 枚举和主机读文件已通过；尚未验证通过 Ventoy 引导系统。新增自动网页文件读写/卸载脚本因用户开始使用虚拟盘未完整重跑 |
| 账户高级功能 | 基础初始化和登录通过；TOTP、账户修改、禁用认证等保留实现，未逐项走完实机流程 |
| Computer Use、Redfish、WOL | 保留实现，未配置外部模型/目标设备并端到端验证；Redfish 电源控制仍受 ATX 硬件缺失限制 |
| 截图、录像、粘贴/宏与快捷键 | 保留网页功能；已有基本键鼠证据不覆盖这些入口的全部行为 |
| 网络与恢复边界 | 未做公网 STUN/TURN、完整冷启动、HDMI 热插拔、长时间运行和异常断电恢复验收 |

## 已有实机证据的主功能

- H.264/H.265 4K 约 60 fps、MJPEG；输入状态、输出分辨率/帧率上限、码率与 MJPEG 质量。
- 4K60 / 1080p60 EDID 切换；共享 HDR 参数保存；视频设置重启保留。
- 实际键盘、鼠标；ISO 上传、主机读取与弹出后的键鼠恢复。
- Ventoy 引导资源随包安装，真实创建和文件读写单元测试不再静默跳过。
- 三应用往返切换；管理器趋势图、HDR 和应用入口共存。

软件基线为 557 项 Rust 测试、4 项助手测试、42 项工作区测试和七组件包校验通过。
结论：核心本地 KVM 链路已适配，但不能称为 One-KVM 全功能验收完成。
